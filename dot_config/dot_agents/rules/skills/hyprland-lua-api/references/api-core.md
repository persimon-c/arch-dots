## 1. `hl.config(table)`

Sets global Hyprland configuration options. Corresponds to old hyprlang `general {}`, `decoration {}`, etc. sections. Can be called multiple times — later calls merge/override.

```lua
hl.config({
  autogenerated = false,   -- removes yellow warning banner

  general = {
    gaps_in = 5,
    gaps_out = 10,
    border_size = 2,
    col = {
      active_border = "rgba(33ccffee) rgba(00ff99ee) 45deg",
      inactive_border = "rgba(595959aa)",
    },
    resize_on_border = false,
    allow_tearing = false,
    layout = "dwindle",
  },
  decoration = {
    rounding = 10,
    rounding_power = 2,
    active_opacity = 1.0,
    inactive_opacity = 1.0,
    shadow = {
      enabled = true,
      range = 4,
      render_power = 3,
      color = "rgba(1a1a1aee)",
    },
    blur = {
      enabled = true,
      size = 3,
      passes = 1,
      vibrancy = 0.1696,
    },
  },
  -- NOTE: animations{} section is valid here for enabled/first_launch_animation,
  -- but individual animation declarations use hl.animation() separately (see §10)
  animations = {
    enabled = true,
    first_launch_animation = true,
  },
  input = {
    kb_layout = "us",
    kb_variant = "",
    kb_model = "",
    kb_options = "",
    kb_rules = "",
    follow_mouse = 1,
    sensitivity = 0,
    touchpad = {
      natural_scroll = false,
    },
  },
  gestures = {
    workspace_swipe = false,
  },
  misc = {
    force_default_wallpaper = -1,
    disable_hyprland_logo = false,
  },
  dwindle = {
    pseudotile = true,
    preserve_split = true,
  },
  master = {
    new_status = "master",
  },
})
```

Key sub-tables: `general`, `decoration`, `animations`, `input`, `gestures`, `misc`, `group`, `xwayland`, `opengl`, `render`, `cursor`, `debug`, `dwindle`, `master`.

## 2. `hl.monitor(table)`

Configure a monitor/display.

```lua
hl.monitor({
  output   = "",           -- "" = all, "DP-1", "HDMI-A-1", etc.
  mode     = "preferred",  -- "preferred", "1920x1080", "1920x1080@144", "2560x1440@165"
  position = "auto",       -- "auto", "0x0", "1920x0"
  scale    = "auto",       -- "auto", 1, 1.5, 2
  -- optional:
  transform   = 0,         -- 0-7 (rotation: 0=normal,1=90,2=180,3=270,4-7=flipped)
  mirror      = "",        -- mirror another monitor's name
  vrr         = 0,         -- 0=off,1=on,2=fullscreen-only
  bitdepth    = 8,
  cm          = "auto",    -- color management
  disable     = false,
})
```

Multiple `hl.monitor()` calls stack up (each applies to matched output).

## 3. `hl.bind(keys, dispatcher_or_fn, options?)`

Bind a key combo to a dispatcher or Lua function.

```lua
-- Simple dispatcher bind
hl.bind("SUPER + RETURN", hl.dsp.exec_cmd("kitty"))

-- Lua function bind
hl.bind("SUPER + SHIFT + X", function()
  hl.dispatch(hl.dsp.window.float({ action = "toggle" }))
end)

-- Multiple actions
hl.bind("SUPER + Tab", function()
  hl.dispatch(hl.dsp.window.cycle_next())
  hl.dispatch(hl.dsp.window.bring_to_top())
end)

-- By keycode (not name)
hl.bind("SUPER + code:28", hl.dsp.exec_cmd("rofi"))

-- Switch binds (e.g. laptop lid)
hl.bind("switch:[switch name]", hl.dsp.exec_cmd("swaylock"), { locked = true })
hl.bind("switch:on:[switch name]", hl.dsp.exec_cmd("notify-send 'lid closed'"))
hl.bind("switch:off:[switch name]", hl.dsp.exec_cmd("notify-send 'lid opened'"))

-- Bind options (third arg table)
hl.bind("SUPER + mouse_down", hl.dsp.workspace.scroll({ dir = "up" }), {
  repeat = true,    -- fires while held
  locked = true,    -- active even on lockscreen
  submap = "name",  -- only active in this submap
})
```

**Modifier keys:** `SUPER`, `SHIFT`, `CTRL`, `ALT`, `CAPS`, `MOD2`–`MOD5`.
Key names from `xkbcommon-keysyms.h` (the part after `XKB_KEY_`).
Mouse: `mouse:272` (left), `mouse:273` (right), `mouse:274` (middle), `mouse_down`, `mouse_up`.
Use `wev` to find key names/keycodes.

### `hl.unbind(keys)`

```lua
hl.unbind("SUPER + RETURN")
```

## 4. `hl.dispatch(dispatcher)`

Execute a dispatcher immediately (vs `hl.bind` which registers for a key).

```lua
hl.dispatch(hl.dsp.exec_cmd("notify-send hello"))
hl.dispatch(hl.dsp.workspace.focus({ workspace = "2" }))
```

Also callable via hyprctl:
```bash
hyprctl eval 'hl.dispatch(hl.dsp.workspace.focus({ workspace = "3" }))'
# shorthand:
hyprctl dispatch 'hl.dsp.workspace.focus({ workspace = "3" })'
```

## 5. `hl.on(event, callback)` / `hl.off`

Register event callbacks. Multiple callbacks per event are allowed.
Max recursion depth: 5. Callbacks have a 100ms timeout.

```lua
local handle = hl.on("window.active", function(w)
  -- w is HL.Window
  print("focused: " .. w.title)
end)

-- Multi-param events
hl.on("workspace.move_to_monitor", function(ws, m)
  -- ws = HL.Workspace, m = HL.Monitor
  print("ws " .. ws.name .. " at x: " .. m.position.x)
end)

-- Remove a specific handler
hl.off(handle)
```

**Warning:** Events fire on every config reload. Use `hyprland.start` (fires only once) for autostart. Avoid double-registering in re-run code paths.

See `references/api-events.md` for the full event list.

## 6. `hl.window_rule(table)` / `hl.layer_rule(table)` / `hl.monitor_rule(table)`

> **IMPORTANT:** The correct function name is `hl.window_rule()`, NOT `hl.rule()`.
> Rules use a `match` table for conditions (props), and top-level fields for effects.
> Rules are evaluated **top to bottom** — order matters.
> Negate a match with `"negative:pattern"` prefix.

### Window Rules

```lua
-- Anonymous rule (no name)
hl.window_rule({ match = { class = "kitty" }, float = true })
hl.window_rule({ match = { class = "kitty" }, size = {800, 600} })
hl.window_rule({ match = { title = "Spotify" }, workspace = "5" })
hl.window_rule({ match = { class = "firefox" }, opacity = 0.9, opacity_inactive = 0.8 })
hl.window_rule({ match = { class = "steam" }, no_fullscreen_request = true })
hl.window_rule({ match = { fullscreen = true }, border_color = "rgb(FF0000)" })

-- Named rule (can be toggled at runtime via hyprctl)
hl.window_rule({
  name  = "move-kitty",
  match = { class = "kitty" },
  move  = {100, 100},
  animation = "popin",
})

-- Negative match
hl.window_rule({ match = { class = "negative:kitty" }, float = true })

-- Move to center of cursor
hl.window_rule({
  match = { class = "kitty" },
  move  = {"cursor_x-(window_w*0.5)", "cursor_y-(window_h*0.5)"},
})

-- Multi-effect rule
hl.window_rule({
  match   = { class = "kitty" },
  float   = true,
  opacity = 0.95,
  opacity_inactive = 0.85,
  no_blur = false,
})
```

**Match props** (inside `match = {}`):
- `class = "regex"` — window class (app_id)
- `title = "regex"` — window title
- `initialClass = "regex"` — class at open time (static effects)
- `initialTitle = "regex"` — title at open time (static effects)
- `tag = "name"` — window tag
- `xwayland = true/false` — XWayland windows
- `floating = true/false` — floating state
- `fullscreen = true/false` — fullscreen state
- `pid = N` — by process ID

**Common effects** (top-level, outside `match`):
`float`, `tile`, `fullscreen`, `maximize`, `no_fullscreen_request`, `size`, `minsize`, `maxsize`, `move`, `workspace`, `opacity`, `opacity_inactive`, `opacity_fullscreen`, `no_blur`, `no_shadow`, `no_border`, `no_anim`, `pin`, `center`, `stayfocused`, `animation`, `border_color`, `scrolling_width`

Variables usable in `move` and `size`: `monitor_w`, `monitor_h`, `window_x`, `window_y`, `window_w`, `window_h`, `cursor_x`, `cursor_y`

### Layer Rules

```lua
hl.layer_rule({ match = { namespace = "notifications" }, blur = true })
hl.layer_rule({ match = { namespace = "notifications" }, ignore_alpha = 0.5 })
hl.layer_rule({ match = { namespace = "waybar" }, no_anim = true })
```

### Monitor Rules

```lua
hl.monitor_rule({ name = "DP-1", rule = "scale 2" })
```

## 7. `hl.workspace_rule(table)`

```lua
hl.workspace_rule({
  workspace   = "1",         -- workspace name or number (mandatory)
  monitor     = "DP-1",      -- bind to monitor
  default     = true,        -- default workspace for monitor
  persistent  = false,       -- keep alive even with no windows
  on_created_empty = hl.dsp.exec_cmd("kitty"),
  -- layout-specific options via layout_opts:
  layout_opts = { orientation = "top" },  -- for master layout
})
```

## 8. `hl.permission(table)`

Control per-app permissions for sensitive APIs.

```lua
hl.permission({
  binary = "/usr/bin/obs",
  type   = "screencopy",   -- "screencopy", "keyboard"
  mode   = "allow",        -- "allow", "deny"
})
hl.permission({ binary = "/usr/bin/hyprlock", type = "screencopy", mode = "allow" })
```

Note: The field is `mode`, not `allow` (there was a stubs bug in 0.55.0 fixed in 0.55.1).

## 9. `hl.curve(name, table)`

Register an animation curve. Use before `hl.animation()` calls that reference it.

```lua
-- Bezier curve
hl.curve("easeOutQuint",   { type = "bezier", points = { {0.23, 1},    {0.32, 1}    } })
hl.curve("easeInOutCubic", { type = "bezier", points = { {0.65, 0.05}, {0.36, 1}    } })
hl.curve("linear",         { type = "bezier", points = { {0, 0},       {1, 1}       } })
hl.curve("almostLinear",   { type = "bezier", points = { {0.5, 0.5},   {0.75, 1}    } })
hl.curve("quick",          { type = "bezier", points = { {0.15, 0},    {0.1, 1}     } })

-- Spring curve (keep mass=1, adjust stiffness/dampening)
hl.curve("easy", {
  type      = "spring",
  mass      = 1,
  stiffness = 71.2633,
  dampening = 15.8273644,
})
```

Design bezier curves at cssportal.com or choose from easings.net.

## 10. `hl.animation(table)`

> **IMPORTANT:** Animations are declared with `hl.animation()` as a **top-level function**, NOT nested inside `hl.config({ animations = { animation = ... } })`.

```lua
hl.animation({ leaf = "workspaces", enabled = true, speed = 8,  bezier = "easeOutQuint" })
hl.animation({ leaf = "windows",    enabled = true, speed = 10, bezier = "easeOutQuint", style = "slide" })
hl.animation({ leaf = "windowsIn",  enabled = true, speed = 5,  bezier = "easeOutQuint", style = "popin 80%" })
hl.animation({ leaf = "fade",       enabled = false })
-- spring curve instead of bezier:
hl.animation({ leaf = "windows",    enabled = true, speed = 1,  spring = "easy", style = "slide" })
```

**Animation tree** (inherits from parent if unset):
```
global
 ↳ windows     — styles: slide, popin, gnomed
    ↳ windowsIn    — window open
    ↳ windowsOut   — window close
    ↳ windowsMove  — moving/dragging/resizing
 ↳ fade
    ↳ fadeIn
    ↳ fadeOut
    ↳ fadeSwitch
    ↳ fadeShadow
    ↳ fadeLayers
    ↳ fadeOnEmpty
    ↳ fadeDim
 ↳ border
 ↳ borderangle  — note: "loop" style causes constant re-render (battery drain)
 ↳ workspaces
    ↳ specialWorkspace
 ↳ layers
    ↳ layersIn
    ↳ layersOut
```

## 11. `hl.layout`

### `hl.layout.register(name, callbacks)`

Register a custom tiling layout. Use as `layout = "lua:columns"` in config.

```lua
hl.layout.register("columns", {
  recalculate = function(ctx)
    local n = #ctx.targets
    if n == 0 then return end
    for i, target in ipairs(ctx.targets) do
      target:place(ctx:column(i, n))
    end
  end,
  -- optional:
  layout_msg = function(ctx, msg)
    -- handle layout messages from hl.dsp.layout(msg)
  end,
})
```

`ctx` provides:
- `ctx.targets` — array of layout targets
- `ctx.area` — work area (HL.Box)
- `ctx:column(i, n)` — divides area into n columns, returns i-th
- `ctx:row(i, n)` — divides into n rows
- `ctx:grid_cell(x, y, cols, rows)` — grid cell
- `ctx:split(box, ratio, dir)` — split a box ("h" or "v")
- `target:place(box)` — place a window
- `target.window` — HL.Window (may be nil)

## 12. `hl.notification`

```lua
-- Create notification
local notif = hl.notification.create({
  text      = "Hello from Hyprland!",
  timeout   = 5000,              -- ms (required)
  icon      = "ok",              -- "ok", "warning", "error", or icon name string
  color     = "rgba(aaffaaff)",  -- optional
  font_size = 14,                -- optional
})

-- Get all active notifications
local notifs = hl.notification.get()  -- → array of HL.Notification

-- Dismiss a notification
notif:dismiss()
```

## 13. `hl.timer(fn, options)`

Run a Lua function on a timer. Returns a timer object.

```lua
-- One-shot timer (e.g. for safe DPMS toggle)
hl.bind("SUPER + F7", function()
  hl.timer(function()
    hl.dispatch(hl.dsp.dpms({ action = "disable" }))
  end, { timeout = 500, type = "oneshot" })
end)

-- Repeating timer
local t = hl.timer(function()
  print("tick every second")
end, { timeout = 1000, type = "repeat" })

-- Control the timer
t:set_enabled(false)
t:set_enabled(true)
t:is_enabled()   -- → boolean
```

**Options:**
- `timeout` — milliseconds between fires
- `type` — `"oneshot"` or `"repeat"`

## 14. `hl.env(key, value)`

Set environment variables before the display server initializes. Two positional args (NOT a table).

```lua
hl.env("XCURSOR_SIZE", "24")
hl.env("HYPRCURSOR_SIZE", "24")
hl.env("GTK_THEME", "Nord")

-- Reference existing env vars via os.getenv():
hl.env("SSH_AUTH_SOCK", os.getenv("XDG_RUNTIME_DIR") .. "/ssh-agent.socket")
```

> **Note (uwsm users):** Avoid `hl.env()` entirely. Use `~/.config/uwsm/env` for theming/xcursor/toolkit vars and `~/.config/uwsm/env-hyprland` for `HYPR*` and `AQ_*` vars. Format: `export KEY=VALUE`.

## 15. `hl.get_config(key)`

Read a config value at runtime. Returns a table for vec2/multi-value types.

```lua
-- Read a config value
local gaps = hl.get_config("general.gaps_in")
-- gaps is a table: { top = N, right = N, bottom = N, left = N }

-- Toggle gaps_in between 0 and 3
hl.bind("SUPER + SHIFT + G", function()
  local g = hl.get_config("general.gaps_in")
  if g.top == 3 then
    hl.config({ general = { gaps_in = 0 } })
  else
    hl.config({ general = { gaps_in = 3 } })
  end
end)
```

## 16. Query Functions

```lua
-- Get the currently active/focused window
local w = hl.get_active_window()   -- → HL.Window or nil

-- Get all windows
local wins = hl.get_windows()      -- → array of HL.Window

-- Get active workspace
local ws = hl.get_active_workspace()  -- → HL.Workspace

-- Get all workspaces
local workspaces = hl.get_workspaces()

-- Get monitors
local monitors = hl.get_monitors()   -- → array of HL.Monitor

-- Get a window by selector string
local w = hl.get_window("class:kitty")
```

See `references/api-objects.md` for fields on these objects.
